# SketchGroup v1.0.0

用于 Blender 场景搭建的原位群组编辑插件。

## 功能

- 双击、Tab 进入集合实例，支持组中组；框外单击、Esc 或空选 Tab 返回。
- 修改直接作用于源对象与网格，关联实例实时同步。
- Shift+D 独立当前层，Alt+D 关联复制，子组保持原有关联。
- Ctrl+G 打组、Ctrl+J 加入组、P 分离与解散；右键支持独立化及选择关联组。
- 可设置三维边界框与组外遮罩；大纲自动折叠，原生选择和编辑操作保留。

## 安装

下载附件 **SketchGroup-v1.0.0.zip**，在 Blender 偏好设置中选择“从磁盘安装”，选择 ZIP 并启用。

最低 Blender 5.0；已验证 Windows / Blender 5.0.1。轮廓遮罩要求 OpenGL，透明贴图边缘不参与遮罩计算。其他系统与后端尚未完整验证。

带变换动画的实例按进入时姿态编辑，退出后恢复动画。早期版本尚未结束的临时编辑／旧坐标会话不再恢复，升级前请退出组编辑并保存。

详细操作见仓库的 `docs/USER_GUIDE.zh-CN.md`。代码采用 GPL-3.0-or-later。
